HOW TO USE

三分钟上手

01

选择根文件夹根目录内有且仅有 5 个包含图片的子文件夹，且图片数量一致。系统按文件名自然排序后，把每个子文件夹的第 N 张图配成一组。

02

选出胜者与败者点击图片下方的「胜者」「败者」。同一张图不能兼任两者；再点一次可取消。

03

保存或丢弃「保存并下一组」写入 JSON；没有明确偏好时点「丢弃本组」，该组不会出现在 JSON 中。

04

随时继续读取根目录下的 scores.json 会自动恢复已有记录，重复评判会覆盖原记录。

Enter 保存并下一组 ← 上一组 D 丢弃本组 Esc 关闭弹窗
输出格式scores.json
{
  "0001": {
    "win": "Ours",
    "lose": "Baseline"
  }
}

记录名默认取 5 张图的共同文件名（不含扩展名）。
